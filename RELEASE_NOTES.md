## 0.1.1 - 2026-08-13

First public release of the read-only `@eliware/ipfix` command-line client.

- Read-only access to the ipfixd health, readiness, performance, metrics, and
  diagnostic APIs.
- Human-readable and JSON output modes for scripting and AI-agent workflows.
- Configuration through command-line options and environment variables.
- Shell completions for Bash, Fish, PowerShell, and Zsh.
- Safe initialization and representative CLI integration tests.
- Jest test execution, Oxlint validation, npm packaging, and CI verification.
